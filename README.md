# Student Mental Health & Academic Performance Dashboard

## Overview

The Student Mental Health & Academic Performance Dashboard is an interactive Power BI dashboard designed to analyze the relationship between students' academic performance, study habits, sleep patterns, and mental health indicators.

The dashboard provides a visual overview of key student metrics and allows users to explore the data using gender and course-level filters.

## Key Performance Indicators

The dashboard provides the following key metrics:

- Average Study Hours: 5.51 hours
- Average Sleep Hours: 6.50 hours
- Average CGPA: 7.00

These KPIs provide a quick overview of students' study patterns, sleep duration, and academic performance.

## Dashboard Features

### 1. Average Study Hours

Displays the average number of daily hours students spend studying.

### 2. Average Sleep Hours

Displays the average number of daily hours students spend sleeping.

### 3. Average CGPA

Displays the overall average CGPA of the students included in the dataset.

### 4. Average Anxiety Score by Gender

A horizontal bar chart compares the average anxiety score across:

- Male
- Female
- Other

This visual allows users to examine differences in average anxiety scores across gender categories.

### 5. Burnout Level Distribution

A donut chart presents the distribution of students across three burnout categories:

- Low
- Medium
- High

The dashboard displays both the count and percentage distribution for each category.

### 6. Stress Level Distribution

A donut chart represents the distribution of students across:

- High
- Medium
- Low

The visual provides an overview of the different stress-level categories in the dataset.

### 7. Study Hours vs CGPA

A line chart visualizes the relationship between daily study hours and average CGPA.

This allows users to explore how academic performance varies across different study-hour levels.

## Interactive Filters

## Dashboard Layout

The dashboard is organized into three major sections:

1. **Summary Metrics**
   - Average Study Hours
   - Average Sleep Hours
   - Average CGPA

2. **Mental Health Analysis**
   - Average Anxiety Score by Gender
   - Burnout Level Distribution
   - Stress Level Distribution

3. **Academic Performance Analysis**
   - Study Hours vs CGPA

Interactive gender and course filters are provided on the right side of the dashboard.

## Purpose

The purpose of this dashboard is to provide a clear and interactive way to explore student academic performance alongside lifestyle and mental-health-related indicators.

By combining academic, behavioral, and mental-health variables into a single dashboard, users can explore patterns within the student dataset through interactive visualizations.
